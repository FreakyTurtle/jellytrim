# Go conventions

Enforced by `.golangci.yml` (golangci-lint v2) and gofmt/goimports. The format hook runs goimports on every Go file written.

- **Standard library first.** `net/http` ServeMux with method patterns, `log/slog`, `database/sql`, `encoding/json`, `os/exec` (only in `internal/ffmpeg`). A new dependency needs a reason in the commit message. Current dependencies: templ, `modernc.org/sqlite`.
- **Size limits.** Lint fails at funlen 80 lines / 60 statements and gocyclo 20. Aim for about 50 lines and complexity 10.
- **Errors.** Wrap with context: `fmt.Errorf("probing %s: %w", path, err)`. Never `%v` an error you return. No `panic` outside `main` and tests. Sentinel errors (`var ErrX = errors.New(...)`) for conditions callers branch on.
- **User-facing errors vs diagnostics.** Types in `internal/plan` and `internal/pipeline` carry a plain-English `Reason` for the UI and separate technical detail for the expandable diagnostics.
- **Logging.** `log/slog` with key/value pairs and a component prefix: `slog.Warn("sync: item skipped", "item", id, "reason", r)`. Never log the Jellyfin API key, full request headers or URLs containing credentials.
- **Context.** Every function that does I/O or runs a process takes `ctx context.Context` first and honours cancellation.
- **No globals.** Dependencies go on structs or are passed as parameters. `time.Now` is injected (a `Clock` or `now func() time.Time`) wherever decisions depend on time.
- **Pure domain packages.** `internal/media`, `internal/policy`, `internal/plan` and `internal/pathmap` do no I/O: no files, no network, no database, no processes. They take data and return decisions.
- **Doc comments** on every exported identifier. Comments explain why, not what.
- **Imports** grouped: stdlib, third party, then `github.com/freakyturtle/jellytrim/...`.
- **Time** is stored and compared in UTC.
- **Sizes** are `int64` bytes. Bitrates are `int64` bits per second. Durations are `time.Duration`.

## Generated code

`*_templ.go` is generated by `go tool templ generate` and committed. Edit the `.templ` file and run `task generate`. A hook blocks direct edits.
